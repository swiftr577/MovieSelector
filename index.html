        Backup and install

        Your lists live in this browser on this device. Save a backup file to move them to another phone or keep them safe. The backup does not include your TMDB key.

        To install: on iPhone, open in Safari, tap Share, then “Add to Home Screen”. On Android, open the Chrome menu and tap “Install app” or “Add to Home screen”.

        Movie data key

        Listings come from TMDB, which needs a free personal key. Create an account at themoviedb.org → Settings → API and paste either the API key or the read access token here. It is saved on this device only.

        This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability by JustWatch. Listings can lag behind the services by a day or two. v1.5
